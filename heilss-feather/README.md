# Feather Wallet on Umbrel

Unofficial Heil store packaging of the unmodified official Feather desktop wallet.

- Image build: `containers/feather`; release signature and pinned hash checked during build.
- Umbrel authentication remains enabled. No VNC or web port is published directly.
- VNC listens only on container localhost; noVNC is behind Umbrel's app proxy.
- Feather runs as UID 1000. `/data` persists settings and wallets.
- On first launch, the existing Monero app RPC settings initialize the custom-node configuration.
- No wallet or seed is generated by the installer. Create or restore one in Feather.
- Use HTTPS or a trusted private network for remote access. Wallet passwords and seed backups remain your responsibility.
- App uninstall removes wallet files. Save the seed and back up wallets beforehand.

The desktop display layer is noVNC/Openbox/Xvfb. This package is not maintained or endorsed by Feather or Umbrel.
